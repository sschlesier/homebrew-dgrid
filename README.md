# Homebrew Tap for DGrid

This is the official [Homebrew](https://brew.sh) tap for [DGrid](https://github.com/sschlesier/dgrid), a modern MongoDB GUI for macOS.

## Install

```bash
brew install --cask sschlesier/dgrid/dgrid
```

## Update

```bash
brew upgrade --cask dgrid
```

## Uninstall

```bash
brew uninstall --cask dgrid
```

## About

DGrid is a modern MongoDB GUI built with Fastify and Svelte. See the [main repository](https://github.com/sschlesier/dgrid) for more information.
